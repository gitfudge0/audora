# Support

Use the issue templates for project support:

- Bug reports: broken behavior, crashes, incorrect scans, failed writes, or installation problems.
- Feature requests: focused improvements to Audora's local-library cleanup workflow.
- Discussions: questions, ideas, and product feedback that do not have a clear bug or implementation request yet.

## Before Asking

- Check the latest release and existing issues.
- Back up any music library before testing metadata, lyrics, or artwork writes.
- Avoid attaching copyrighted audio files. Share metadata, screenshots, logs, or synthetic sample files instead.

## Useful Details

For app problems, include:

- Audora version.
- Android version and device model.
- File format, such as MP3, FLAC, M4A, OGG, or OPUS.
- Storage location, such as internal storage, SD card, synced folder, or SAF-picked folder.
- Exact steps to reproduce.
- Screenshots or `adb logcat` output when available.

For build problems, include:

- Operating system.
- JDK version.
- Android SDK or Android Studio version.
- The Gradle command that failed.
- The relevant error output.

## Project Boundaries

Audora is a local music metadata workspace, not a streaming service or cloud music locker. Support requests that require uploading private libraries, bypassing DRM, distributing copyrighted files, or recovering lost files from unrelated tools are outside the project scope.
