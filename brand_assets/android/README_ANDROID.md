# Android Assets

This folder includes:

- `drawable/ic_audora_mark.xml`: monochrome vector mark.
- `drawable/ic_audora_mark_ivory.xml`: ivory vector mark.
- `drawable/ic_launcher_foreground.xml`: adaptive icon foreground for light background.
- `drawable/ic_launcher_foreground_dark.xml`: adaptive icon foreground for dark background.
- `mipmap-anydpi-v26/ic_launcher.xml`: adaptive icon definition.
- `mipmap-anydpi-v26/ic_launcher_dark.xml`: dark adaptive icon definition.
- `mipmap/mipmap-*`: PNG launcher fallbacks.
- `play-store`: 512 px Play Store icons.

Copy `android/values/colors.xml` into your app resources, then copy the drawable and mipmap folders into `app/src/main/res/`.
